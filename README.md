## 🏛️ Core Design Patterns
1. **Supervisor & Worker Hierarchy**: Central orchestrator decomposing goals and delegating sub-tasks.
2. **ReAct (Reason + Act)**: Interleaving thought, action, and observation cycles.
3. **Model Context Protocol (MCP)**: Open standard connecting LLMs to local filesystems, DBs, and dev tools.
4. **Human-in-the-Loop (HITL)**: Stateful checkpoints for risk-sensitive action authorization.
